# Нормативы

**Приоритет: ШНҚ Узбекистана всегда главнее.** Объекты строятся в Узбекистане,
поэтому при расхождении принимается ШНҚ. СП РФ, ГОСТ, ASHRAE применяются
только там, где в ШНҚ пробел — акустика, психрометрия, комфорт, формы
энергопаспорта. Решение пользователя, не обсуждается заново.

Правило: **значение из нормы — со ссылкой на документ и пункт**. Не «кратность 3»,
а «ШНҚ 2.08.02-23, прил.9 табл.22, п.14 — 3 ч⁻¹». Если пункт не найден —
так и скажи, не подставляй правдоподобное число.

## Первоисточники — библиотека D:\NORMS

Девять действующих норм Узбекистана с официального `main.tmsiti.uz`,
список и подробности — `D:\NORMS\README.md`. Ключевые для ОВиК:
`SHNQ_2.04.05-22` (ОВК), `SHNQ_2.08.02-23` (общественные здания),
`SHNQ_2.08.01-24` (жилые), `SHNQ_2.05.07-24` (автостоянки),
`KMK_2.01.04-18` (теплотехника, R₀ᵗᵖ), `SHNQ_2.01.18-24` (расход энергии).

```
python D:\NORMS\find_norm.py --list                    # что есть
python D:\NORMS\find_norm.py "тамбур-шлюз"             # по всем документам
python D:\NORMS\find_norm.py "ҳаво алмашинуви" -d 2.08.02
python D:\NORMS\find_norm.py --page 68 -d 2.04.05      # страница целиком
```

**`KMK_2.01.04-18` — скан без текстового слоя**, поиском не берётся: нужную
страницу рендерить в PNG (рецепт в README) и читать глазами. Ориентиры:
стр. 7 — табл. 2а, стр. 8 — 2б, стр. 9 — 2в, стр. 10 — табл. 4.

Копия четырёх ШНҚ есть и в `D:\HVAC\tools\shnk\` со своим `shnk_find.py` —
дублирует библиотеку, при расхождении опираться на `D:\NORMS`.

Чего в библиотеке **нет**: строительная климатология (2.01.01) — а из неё
расчётные температуры и градусо-сутки; противопожарные (2.01.02);
наружное водоснабжение (2.04.02). На tmsiti.uz по обычному пути не нашлись.

**Тексты на узбекском.** Русский термин чаще всего не найдётся — ищи оба
варианта: расход воздуха — `ҳаво сарфи`, кратность воздухообмена —
`ҳаво алмашинуви`, температура — `ҳарорат`, влажность — `намлик`,
приложение — `ИЛОВА`, таблица — `жадвал`, помещение — `хона`.
Номера пунктов идут в тексте как «203. …».

Уже извлечённые таблицы 18–19 (расчётные параметры общественных зданий):
`tools/shnk/_tables_82-92.txt`.

## Данные, которым нельзя верить на слово

Это не придирки — это места, где ошибка уже возможна:

- **`kmk_thermal.py` (R₀ᵗᵖ по КМК 2.01.04-18)** — числа получены OCR со скана.
  **Табл. 2а сверена по официальному PDF 2026-08-01**: 59 из 60 значений
  верны, одно исправлено (общественные здания, полоса Dd 2000–3000, фонари:
  было 0,31, по норме 0,30). Спорная ячейка `public[2]` подтверждена.
  В табл. 2б сверены стены и покрытия — совпали. **Не сверены**: окна,
  фонари и полы в 2б и вся табл. 2в. При расхождении расчёта с ожиданием
  проверять эту таблицу первой.
- **`norm_per_m2` в `smoke_norms.py`** — «м³/ч на 1 м²» это эмпирическое
  упрощение, восходящее к СНиП 2.04.05-91*. В действующих сводах такого
  подхода нет: и СП 7, и КМК, и NFPA 92 считают дымоудаление по физике
  (плюм-теория, мощность пожара, перепад давления). Годится для прикидки
  оборудования, не для сдаваемого расчёта.
- **`engine/kmk.py` ссылается на КМК 2.04.05-91**, тогда как действующий
  документ — ШНҚ 2.04.05-22, и его PDF лежит в проекте. Сознательно
  сохранена надбавка СНиП 2.04.05-91 на угловое помещение. Прежде чем
  менять — уточни у пользователя, а не «исправляй» молча.

## Сверка движка отопления с ШНҚ 2.04.05-22 (2026-08-01)

Проверено прил. 9 «Хоналарнинг тўсиқ конструкциялари орқали ўтадиган иссиқлик
сарфи» (стр. 68–69) против `engine/sp50.py`, `engine/kmk.py`, `models.py`.
Формула совпадает: ШНҚ (1) `Q = A(tp−text)(1+Σβ)n/R` ↔ код
`Q = Σ K·F·(tв−tн)·n·(1+Σβ) + Qинф − Qбыт`, где K = 1/R.

Расхождения найдены, **код не правился** — решение за пользователем:

1. **Восток занижен.** ШНҚ п.2: С, В, СВ, СЗ → 0,1; ЮВ и З → 0,05.
   В `models.py: beta_orientation` стоит `E: 0.05`, должно быть `0.1`.
   Остальные восемь румбов совпадают. Та же норма и в СНиП 2.04.05-91,
   откуда таблица бралась, — похоже на опечатку, а не на решение.
2. **Надбавка на угловое помещение.** `KMKEngine._corner_room_addition`
   даёт +0,05. ШНҚ п.2 для двух и более наружных стен: 0,15 в общественных,
   административно-бытовых и производственных зданиях (0,1, если одно из
   ограждений на С/В/СВ/СЗ); для типовых проектов — 0,08 при одной стене
   и 0,13 при двух и более, кроме жилых. Значения 0,05 в норме нет.
3. **Надбавка на высоту >4 м.** Код добавляет β = (h−4)·0,02 ≤ 0,15.
   В ШНҚ п.1 высота учитывается ростом расчётной температуры tp, а не
   надбавкой β. Разные механизмы с разным результатом.
4. **Нет надбавок на наружные двери и ворота.** ШНҚ п.2 при отсутствии
   воздушной завесы: тройные двери с двумя тамбурами 0,2·H, двойные
   с тамбуром 0,27·H, двойные без тамбура 0,34·H, одинарные 0,22·H;
   ворота без тамбура 3, с тамбуром 1 (H — высота здания, м).
5. **Нет зонального расчёта полов по грунту.** ШНҚ п.3: полосы 2 м
   параллельно наружным стенам, Rc = 2,1 / 4,3 / 8,5 / 14,2 (зоны I–IV);
   для утеплённых Rh = Rc + δ/λ, по лагам Rh = 1,18·(Rc + δ/λ).

Пункты 1–2 меняют результат на существующих объектах, 4–5 — пробелы
методики. Прежде чем править — согласовать с пользователем: пересчёт
затронет уже сданные расчёты.

## Как добавлять новое

Новая формула или коэффициент — со ссылкой на пункт в докстринге, как в
существующих движках. Значение без источника в код не попадает.
Табличные данные — в `hvac/catalogs/data/*.json`, не хардкодом.

Если норма расходится с практикой заказчика (так было с бытовыми
теплопоступлениями и с разделением кухонь по типам) — решение за
пользователем; фиксируй его в докстринге вместе с причиной.
