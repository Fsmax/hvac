# HVAC Calculator — рабочие правила

Продукт: десктоп-приложение расчёта ОВиК+ГВС (Python 3.13 + PySide6), связанное
с живым Revit через сокет-мост. Структура пакета — в [ARCHITECTURE.md](ARCHITECTURE.md),
читай его перед правкой расчётных модулей.

## Два профиля работы

| Профиль | Для чего | Как включить |
|---|---|---|
| **инженер** | работа по объекту: живой Revit, разметка, расчёт, экспорт | `/engineer` |
| **разработчик** | код продукта: `hvac/`, тесты, рефакторинг, UI | `/developer` |

Полные роли — в `.claude/agents/engineer.md` и `.claude/agents/developer.md`.

Скиллы (загружай по теме задачи, не все сразу):
`hvac-norms` — нормативы ШНҚ/КМК/СП, PDF первоисточников и поиск по ним ·
`revit-bridge` — мост в живую модель · `revit-api` — сам API, единицы,
транзакции, MEP · `revit-plugin` — .NET add-in, csproj, .addin, деплой ·
`revit-family` — шаблоны .rft и авторинг семейств.

Главное различие: инженер не правит код пакета, разработчик не запускает
массовую запись в живую модель. Если профиль не выбран — спроси, какой,
когда задача явно попадает в одну из двух областей.

## Мост в живой Revit — правила

Транспорт: `hvac.revit_link` → сокет `127.0.0.1:8080` → плагин в Revit.
`revit_link.ping()` проверяет связь; `send_code(cs)` шлёт C#; `call(method, params)` — RPC.

1. **Плагин имеет exec-timeout.** Массовую операцию дроби на батчи (~20 элементов
   на вызов) — иначе таймаут, и коммит будет частичным.
2. **Одна транзакция за вызов.** При сбое середины батча уже применённое
   остаётся в модели.
3. **Перед любой массовой правкой пиши откат** — `*_ids.json` со списком
   созданных/изменённых ElementId рядом со скриптом. Без него отката нет:
   .rvt не под контролем версий.
4. В логе Revit `"Failed to create command instance"` — **это успех**,
   сообщение мислейбл. Не считать ошибкой.
5. `.rvt` сохраняет пользователь вручную. Не предлагать автосохранение.
6. Встроенный occupancy у Space — read-only. Писать только в свои параметры.
7. `aec:number` (нагрузки фанкойлов и т.п.) пишутся в ваттах как есть.
   **Не умножать на 10.764** — единицы уже приведены.
8. Ручные значения расходов, введённые в модели, не пересчитывать.

Импорт: `revit_link.import_from_revit(folder)` — флаги `clean_glazing` и
`geom_exterior` включены по умолчанию, они чинят двойной учёт витража
(ARC+FCD) и стены ядра, ошибочно считавшиеся наружными. Не отключать.

## AutoCAD

Разметку и авторинг делаем **только в Revit**. COM-мост к AutoCAD рабочий,
но использовать его для черчения не надо — прямое указание заказчика.

## Гигиена репозитория

- В корне лежат исторические `_probe_*.py`, `_scratch_*.py`, `_*.txt`, `_*.tsv` —
  это отработанные разовые пробы. При поиске по коду их игнорировать,
  за образец не брать.
- Расчётные `.csv`/`.xlsx`/`.hvac.json` в корне — данные объектов, не трогать.
- Нормативы: КМК Узбекистана + СП РФ. Новые формулы — со ссылкой на пункт
  норматива в докстринге, как в существующих движках `hvac/engine/`.
