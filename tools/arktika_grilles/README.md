# Генератор каталога решёток (ARKTIKA/Арктос → grilles.json)

Извлекает таблицы подбора воздухораспределительных решёток из PDF-каталога
ARKTIKA/Арктос («Оборудование для систем вентиляции», изд. 8.02) и собирает
встроенный каталог `hvac/catalogs/data/grilles.json`, который использует
`hvac/grille_catalog.py` (подбор) и вкладка «Решётки» панели «Инженерия».

Это офлайн-инструмент разработчика. В рантайме приложения он не нужен —
приложение читает уже собранный `grilles.json`.

## Зависимость

```
pip install pymupdf
```
(только для регенерации; в `requirements.txt` приложения не входит.)

## Запуск

```
python build_json.py "C:\path\to\ARKTIKA_v8.02.pdf"
# либо
set ARKTIKA_PDF=C:\path\to\ARKTIKA_v8.02.pdf
python build_json.py
```
Путь к PDF — первый аргумент `*.pdf` или переменная окружения `ARKTIKA_PDF`.
Результат пишется в `../../hvac/catalogs/data/grilles.json` и сводка в
`build_summary.txt`.

Проверка структуры одной страницы (отладка парсера):
```
python build_grilles.py            # валидация стр.387 -> validate_387*.txt
python build_grilles.py --audit    # обзор всех страниц решёток -> report_all.txt
```

## Как это работает

`build_grilles.extract_page` — геометрический парсер шумовых таблиц: через
`fitz.find_tables()` берёт сетку, по координатам слов определяет полосы шума
(`LwA≤20/25/35/45 дБ(А)`), столбцы `L0`/`ΔPполн`/дальнобойности и собирает по
каждому типоразмеру рабочие точки `{lwa, l0, dp, throw{Vx}}`.

`build_json` — карта «страница → семейство» (`FAMILY_MAP`) + спец-парсеры:
переточные АП (по скорости в живом сечении) и напольные РНБ/РНР (только F0,
аэродинамика в каталоге дана номограммой). Извлекает и таблицу регулятора
расхода (K, ΔLwA) для вариантов «-Р».

## Покрытие (изд. 8.02)

14 семейств, ~319 типоразмеров (раздел «Воздухораспределительные устройства»,
стр. 386–415, α=0° — подача или удаление):

- Настенные: АМН/АМР/АДН/АДР, ПРН/ПРР, РСН/РСР, АЛН/АЛР, АБН/АБР
- С присоединительной камерой (-К): АМ/АД-К, ПР-К, РС-К, АЛ-К
- Для круглых воздуховодов: КМУ, КДУ/КДН
- Щелевые: АРС/АЛС/АВС (на 1 м длины)
- Переточные: АП (по скорости)
- Напольные: РНБ/РНР (по скорости; ΔP по номограмме изготовителя)

Отложено (другой/составной layout, можно добавить позже): КМН (стр. 410),
направленные таблицы α=45° (стр. 388/389/398/399), диффузоры (стр. 416–520).
Добавление — правкой `FAMILY_MAP` без изменения кода приложения.
